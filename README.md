# 智能客服退货流程 Skill

一个平台无关的客服产品设计与实现技能：覆盖产品架构、模块职责，以及退货诉求、订单识别、原因了解、政策方案、顾客选择和执行结果的完整流程。

核心约束：**模型理解和表达，业务规则决定资格与金额，接口执行并确认真实结果。**

## 包含内容

- [SKILL.md](SKILL.md)：技能入口、职责边界与交付要求。
- [产品架构设计规范](references/architecture.md)：可渲染的架构图、模块职责、数据流与执行授权边界。
- [流程与状态](references/workflow.md)：完整分支、协商次数、正常退货及人工出口。
- [数据与执行约定](references/contracts.md)：方案白名单、回复校验、接受证据、幂等与统计。
- [行为验收](references/acceptance.md)：可重放的输入与预期结果。
- [回复 schema](schemas/offer-response.schema.json) 与 [虚构示例](examples/offer.json)：结构化输出格式及完整样本。

## 安装与调用

下载或克隆本仓库，把整个 `returns-support-skill` 文件夹放入所用助手支持的技能目录；保留 `SKILL.md` 与各子目录的相对位置。支持标准技能发现的环境可按任务自动使用；支持显式调用的环境可输入 `$returns-support-skill`。

示例任务：

> 使用 `$returns-support-skill`，为我们的退货客服设计状态机、接口输入输出和验收用例。已有订单查询、库存查询和退货入口，政策配置稍后提供。

> 使用 `$returns-support-skill`，按产品架构规范设计渠道入口、会话编排、政策引擎、模型网关、防护层和执行器，标明各模块的读写权限及失败出口。

> 使用 `$returns-support-skill`，检查这段客服实现是否会执行白名单之外的方案、重复发放权益，或者在顾客拒绝后继续挽留。

## 范围

这是用于设计、实现和评审的技能包。真实运行需要接入订单、政策、库存、身份验证和执行服务；示例中的金额、期限与业务标识均为虚构数据。

非退货问题交回既有客服；没有允许方案或顾客拒绝时进入正常退货流程；校验失败时使用模板、转人工并记录原因。正常退货资格由既有流程判定。

所有内容使用通用业务概念，不依赖特定服务商、模型或技术框架。仓库包含文字规范、可渲染架构图与结构化示例。
